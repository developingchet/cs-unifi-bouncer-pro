# Code of Conduct

## Our Standards

This project is a focused, technical open source tool. We expect all participants to:

- Be respectful and constructive in all interactions
- Focus feedback on code and ideas, not individuals
- Accept differing technical opinions graciously
- Prioritize the security and reliability goals of the project

Unacceptable behavior includes harassment, personal attacks, trolling, and any conduct that would be inappropriate in a professional setting.

## Scope

This Code of Conduct applies to all project spaces: GitHub issues, pull requests and any other venue where project participants interact.

## Enforcement

Instances of unacceptable behavior may be reported privately by opening a [GitHub security advisory](https://github.com/developingchet/cs-unifi-bouncer-pro/security/advisories/new), or by using the contact method listed on the maintainer's GitHub profile. Do not post conduct reports in public issues. The maintainer reviews reports and decides on a response; this is a single-maintainer project with no separate moderation team.

Maintainers have the right to remove, edit, or reject any contributions that do not align with this Code of Conduct, and may temporarily or permanently ban contributors for behavior they deem inappropriate.
